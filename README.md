Official web application for **Yuva Chaitanya Charitable Trust** — a non-profit organization based in Visakhapatnam, Andhra Pradesh, India. Built with HTML5, Vanilla CSS3, and JavaScript, featuring an interactive **Section 80G Tax Savings Calculator**, donor account management, and an **automated 80G Tax Exemption Receipt generator**.

---

## 🌟 Key Features

- **📜 Section 80G Tax Exemption**:
  All contributions to Yuva Chaitanya Charitable Trust are eligible for **50% Tax Deduction** under Section 80G of the Indian Income Tax Act, 1961.

- **🧮 Interactive 80G Tax Savings Calculator**:
  Real-time calculation showing exact tax savings based on donation amount (₹10 to ₹1,00,000) and tax slab (10%, 20%, or 30% + cess).

- **🧾 Instant 80G Tax Exemption Certificate**:
  Automated generation of official digital receipts including Receipt Serial Number, Donor PAN, donation amount in words & numbers, digital seal, and a one-click **Print / Download PDF** action.

- **💳 Strict Donation Range Validation**:
  Built-in client-side validation enforcing donation bounds between **₹10 minimum** and **₹1,00,000 maximum** (1 Lakh) per transaction.

- **👤 Donor Account Portal**:
  Account creation and login system powered by `localStorage` persistence. Donors can view their contribution history and re-download 80G receipts at any time.

- **❤️ Social Impact Causes**:
  - Child Education & School Supply Distribution
  - Free Rural Healthcare & Eye Camps
  - Elderly & Destitute Relief
  - General Trust Welfare Fund

## 💻 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/lokeshsugandham/ycc--website.git
   ```
2. Navigate into the directory:
   ```bash
   cd ycc--website
   ```
3. Open `index.html` in any web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari).
